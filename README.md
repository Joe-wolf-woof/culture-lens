# 拡張翻訳・空間ウィンドウ（MVP）

JOEの超長期ビジョンの第一実験機。
「言語の翻訳」ではなく、映像の中の風景やモノの背景にある**文化・歴史・語り手の感情**までを空間上に視覚化するWebARプロトタイプ。

## 体験フロー（最初の実験：日本のディープな日常を英語圏へ）

1. スマホでこのページを開き「📷 カメラ起動」
2. 語り手（JOE）が日本の日常・路地裏・チャイを淹れる手元などを映し、「🎙 語る」で自分の言葉で数秒語る（手入力も可）
3. 「🌐 拡張翻訳する」→ カメラフレーム＋語りをGeminiへ送信
4. 画面に英語の拡張字幕＋「異文化の背景知識タグ」がThree.jsで空間にピン留め表示される
5. 画面端の「この体験に100円送る」疑似ボタンで、共感の対価を疑似計測する

APIキーが無い場合は「デモデータで試す」にチェックすると、チャイのサンプルデータで全UIを確認できる。

## 設計

- `index.html` / `css/style.css` — UI（カメラステージ、字幕、タグカード、実験パネル）
- `main.js` — カメラ、音声認識、Three.js空間タグ、疑似チップ、計測の配線
- `engine/translate-engine.js` — 拡張翻訳エンジン。プロンプトに心理学の仕掛けを組み込み済み：
- 情報ギャップ理論（Loewenstein）：驚きのギャップは1つに絞る
- 自己関連効果：受け手の日常と接続する一文を必須化
- 具体性効果：抽象論ではなく感覚（匂い・手触り・音・温度）で語る
- Geminiモデルフォールバック（3.x系→、404/429/503で次モデルへ）はHowLinkと同方式
- `engine/metrics.js` — 実験ログ（localStorage蓄積、JSON書き出し、API原価の概算）

## 回収する「4つの壁」データ

アプリ下部の実験パネルがそのまま計測器になっている。

| 壁 | 計測方法 |
|---|---|
| 1. 技術的限界 | 送信→API応答→描画のレイテンシ内訳、画像KB、電池残量を自動記録 |
| 2. Big Techとの差 | 同じ景色への Gemini Live / Googleレンズの説明メモと、好奇心スコア（1〜5）の差分を記録 |
| 3. 個人開発の限界 | 開発メモタブで「時間を忘れた領域／苦痛な領域 × 分野」を記録 → 将来の相棒・外注の特定 |
| 4. 資本力・経済モデル | 1分体験あたりの通信量（MB）とAPI原価（円）を自動換算。支払い意向タブで「いくらまで払うか」の実測を蓄積。疑似チップの押下も記録 |

## ローカル起動

```bash
cd extended-translation-window
python3 -m http.server 8080
# スマホからは https または localhost が必要（カメラ・マイクの制約）
```

## 注意

- Gemini APIキーは設定画面から入力し、端末のlocalStorageにのみ保存される。コードやリポジトリには含めない。
- 原価は概算（Gemini Flash系の公開価格と画像560token/枚の前提）。実測請求とは異なる。
- 空間タグのピン留めは固定カメラ近似（2Dカメラのみ、専用ゴーグルなしの限界そのものが壁1の計測対象）。
